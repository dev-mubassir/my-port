# Mubassir Shah - Personal Portfolio

Personal portfolio website for Mubassir Shah, an AI/ML-focused student and indie SaaS builder targeting AI Product, AI/ML, Generative AI, and Agentic AI roles, and showcasing Siffty.

## Stack

- Runtime: Vanilla JavaScript (ES2022 modules), HTML5, CSS3
- Bundler: Vite
- Animation: GSAP (with ScrollTrigger), Lenis
- Image Processing: Sharp
- Testing: Playwright

## Getting Started

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

## Structure

```
├── assets/             # Cutouts, reference media, documents
├── src/
│   ├── data/           # Structured text and project content
│   ├── modules/        # Modular JS components (hero, glitch, rotator, etc.)
│   ├── styles/         # CSS design tokens, base, and component styles
│   └── main.js         # Application bootstrap
├── index.html          # Semantic HTML shell and critical hero content
└── vite.config.js      # Vite build configuration
```
