# User Deliverables & Post-Launch Action Items

All required assets, preview compositions, and code updates are complete and operational.

1. **GitHub Pages Activation**: In your GitHub repository settings under **Settings > Pages**, set **Source** to **GitHub Actions** so that `.github/workflows/deploy.yml` deploys the portfolio automatically to `https://dev-mubassir.github.io/my-port/`.
2. **Custom Domain (Optional)**: If you purchase or link `mubassir.dev` or a custom domain, add a `CNAME` record in GitHub Pages settings.
3. **Web3Forms Access Key (Optional)**: In `src/modules/contact.js`, set your free Web3Forms access key if you prefer background AJAX form submission over the built-in direct email dispatcher.
