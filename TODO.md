# User Deliverables & Post-Launch Action Items

Items that use clean placeholders and will need real assets dropped in:

1. **Resume File**: Drop your official `Mubassir_Shah_Resume.pdf` into `assets/Mubassir_Shah_Resume.pdf` replacing the placeholder PDF.
2. **Project Screenshots**: Once ready, drop screenshots for Siffty, DealRadar, CityKirana, and Sky Jump into `assets/projects/` (the project cards have designated visual slots ready to display them).
3. **Web3Forms Access Key** (optional): In `src/modules/contact.js`, set your free Web3Forms access key if you prefer direct form submission over standard `mailto:` action.
4. **GitHub Pages Activation**: In your GitHub repository settings under **Settings > Pages**, set **Source** to **GitHub Actions** so that `.github/workflows/deploy.yml` deploys the portfolio automatically.
